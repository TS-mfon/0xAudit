# 0xAudit V2 Backlog

These features were intentionally removed from the public V1 product so the first deployed release can focus on one strong flow: paste Solidity code, run a live GenLayer audit, and display contract-backed activity.

## Payments And Credits

V2 should add paid audit credits with ETH and USDC payment verification. The frontend should let users select a tier, pay on the configured chain, and then call a server endpoint that verifies the transaction before crediting audit runs.

## Audit Certificates

V2 should issue verifiable audit certificates after completed audits. The GenLayer registry should store the certificate hash, and an EVM soulbound NFT can represent the certificate for the submitter.

## Public Badge And Verifier

V2 should expose public badge pages and certificate verification pages. Badge pages should show only safe public metadata: verdict, score, contract hash, date, and proof references.

## Follow-Up Hardening Loop

V2 should bring back iterative sessions. Users should be able to apply suggested patches, re-audit the changed code, and compare score movement across iterations.

## PDF And IPFS Reports

V2 should generate professional PDF reports and upload report artifacts to IPFS or Arweave. The report should include executive summary, findings, invariants, remediation checklist, and proof metadata.

## GitHub Repository Scanning

GitHub scanning is not a simple direct fetch for production. It needs OAuth or a GitHub App installation, permission handling, token encryption, recursive tree walking, rate-limit management, queues, webhook verification, and clear user consent.

V2 should implement:

- GitHub App installation.
- Repository selector.
- Solidity file tree scan.
- Recursive repo scan queue.
- Pull request checks.
- Diff-aware scans on push.
- Optional fix PR creation.

## CI/CD Integration

V2 should post GitHub Checks API results and PR comments. The check should fail when an audit returns Critical or High findings.
